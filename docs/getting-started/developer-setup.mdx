## What You'll Build

In this tutorial, you'll set up the full Pixelated Empathy platform on your
local machine — frontend, AI services, and all. By the end, you'll have a
running development server and be able to run the test suite.

**Prerequisites:** Node.js 19+, Python 3.11+, pnpm, MongoDB, Redis, Docker
(optional)

---

## Step 1: Clone the Repository

```bash text
git clone https://github.com/daggerstuff/pixelated.git
cd pixelated
```

The repository contains the main platform. The AI engine is a submodule and the
Foresight memory system is a separate repository — see
[Products](/products/pixelated/overview) for the full ecosystem map.

---

## Step 2: Install Dependencies

```bash
# Frontend and Node dependencies
pnpm install

# Python AI/ML services
cd ai-services
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cd ..
```

Notice that the platform uses two package managers: `pnpm` for Node/TypeScript
and `pip` (or `uv`) for Python. The AI services run as a separate process.

---

## Step 3: Configure Environment

```bash text
cp .env.example .env
```

Key variables to set:

```bash
# Database
MONGODB_URI=mongodb://localhost:27017/pixelated-empathy
REDIS_URL=redis://localhost:6379

# AI Services
LLM_API_KEY=your_llm_api_key
FINE_TUNED_THERAPEUTIC_MODEL=meta-llama-3-8b-instruct

# Auth
AUTH_SECRET=your_auth_secret_here
```

<Warning>Never commit `.env` to version control.</Warning>

---

## Step 4: Start the Development Server

```bash
# Full stack (frontend + API)
pnpm dev

# AI services (separate terminal)
cd ai-services
source .venv/bin/activate
python -m uvicorn main:app --reload --port 8000
```

The frontend will be available at `http://localhost:4321`.

Notice that `pnpm dev` starts the Astro dev server with hot module replacement.
The AI services run separately so you can restart them independently when
working on model code.

---

## Step 5: Run Tests

Verify your setup by running the test suite:

```bash
# Unit and integration tests
pnpm test

# End-to-end tests
pnpm test:e2e

# Python AI service tests
cd ai-services
python -m pytest
```

If all tests pass, your local environment is ready for development.

  <Accordion title="Project structure" icon="folder-tree">
    ```text
    pixelated/
    ├── src/                    # Astro + React frontend
    │   ├── components/          # Dashboard, simulator, etc.
    ```
