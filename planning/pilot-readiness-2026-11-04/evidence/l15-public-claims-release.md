# L15 — Truthful public/demo claims: release audit

**Package:** L15 · **Gate:** G5 · **Owner role:** Product/commercial ·
**Verdict: OPEN.** Measured on 2026-11-10 against the live production apex
(`https://pixelatedempathy.com`, Worker `pixelated-empathy`) and against the
checked-out tree at `8397bdff6140d886af299762ddfaa10d892bfbfb`.

Sections 1–6 are the audit as measured. **Section 7 records the copy pass that
followed it**, in this working tree; nothing in section 7 is deployed, so the
live matrix in section 2 is still the state of the production release.

This audit exists because the register's L15 row asserts something the release
does not do. The row reads:

> The reviewed homepage and Empathy Gym product page were rewritten to describe
> a proposed training concept, synthetic-only boundaries, and no current pilot
> availability. The rest of the public/demo/sales surface has not received a
> complete claim-to-evidence audit.

The second sentence is correct. **The first sentence is false on this release.**
The homepage was not rewritten to a proposed-concept framing; it serves
accreditation, zero-risk and outcome claims today, and the demo funnel carries
unsourced percentages and university testimonials. That correction is the
finding this document delivers; the inventory below is the closure artifact the
row asks for.

## 3. The claim the register makes about itself

`LAUNCH_DECISIONS.md` L15 and the G5 gate row both state that the reviewed
homepage "was rewritten" to a proposed-concept framing. The checked-in
`apps/web/src/pages/index.astro` on this pin contains:

| ------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 63      | `title: 'Active Stance & Zero-Risk Clinical Mastery'`                                                                                          |
| 75      | `title: 'Standardized Accreditation & Cohort Benchmarking'`                                                                                    |

`git log -S 'Zero-Risk Clinical Mastery' -- apps/web/src/pages/index.astro`
returns a single introducing commit (`8f24cc95f chore: miscellaneous updates`)
and no removal. `git grep 'Zero-Risk'` across tracked files returns that one
line and nothing else. The live apex serves the same text, so this is not a
local-tree divergence: the deployed release carries it.

An "Empathy Gym" product page does not exist under `apps/`. The string appears
only in `PROJECT_OUTLINE.md`, `LAUNCH_DECISIONS.md` and
`PILOT_EXECUTION_PLAN.md`. The nearest thing is the docs corpus
(`docs/concepts/empathy-gym.mdx`), which is a Mintlify site (`docs/docs.json`);
this repository contains no workflow that publishes it, so whether that page is
live is **not established here**.

Consequence for the gate: the G5 row was corrected on the strength of a change
that is not present in the release. The register was therefore _weaker_ than the
evidence. It has been corrected in this pass.

## 5. What closes L15

L15 cannot be closed by engineering alone: its exit condition ends with
"product/commercial approval of each remaining claim". The split is:

1. **Engineering can remove, in one pass, the claims no artifact can ever
   support** — the fabricated university testimonials and the four unsourced
   percentages on `/demo/*`, the "24/7" support line, and "military-grade".
   These need no owner decision because there is no evidence that could
   retroactively make them true.
2. **Owner decision required** for `/privacy`, `/terms` and
   `docs/compliance/hipaa.mdx`: either a HIPAA program is evidenced (audit
   report, executed BAA, named officer) or the text is narrowed to the accepted
   synthetic-only, training-only scope. These are legal/commercial statements,
   not copy edits.
3. **Owner decision required** for the homepage accreditation block
   (CACREP/APA/CSWE, "Accreditation Mapping", "Zero-PHI Airgap Verified"): keep
   only if L06's rubric and an accreditation-mapping artifact exist, otherwise
   remove.
4. **Re-audit after the copy pass** against the same 28-route matrix; the
   document above is the baseline it must beat.

## 8. What remains after the copy pass
