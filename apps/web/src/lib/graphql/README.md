# GraphQL SDK — Pixelated Empathy

Type-safe GraphQL client generated from the Pixelated Empathy GraphQL schema.

## Installation

The SDK is part of the Pixelated Empathy codebase and uses `graphql-request` for
isomorphic (Node + browser) HTTP transport.

## Quick Start

```typescript
import { createGraphqlClient } from '@/lib/graphql/client'

// API key auth (developer API)
const client = createGraphqlClient({
  endpoint: 'http://localhost:5173/api/graphql',
  apiKey: 'pk_...',
})

// JWT auth (session-based)
const jwtClient = createGraphqlClient({
  endpoint: 'http://localhost:5173/api/graphql',
  jwt: 'eyJhbGci...',
})

// Health check (public)
const { health } = await client.health()
console.log(health) // "ok"

// Get a session
const { session } = await client.getSession({ id: 'session-123' })

// List sessions
const { sessions } = await client.listSessions({
  status: 'COMPLETED',
  limit: 10,
  offset: 0,
})

// Get emotion analyses for a session
const { emotions } = await client.getEmotions({ sessionId: 'session-123' })

// Get intervention records
const { interventions } = await client.getInterventions({
  userId: 'user-456',
  limit: 20,
})

// Get anonymized metrics (admin only)
const { anonymizedMetrics } = await client.getAnonymizedMetrics()
```

## Subscriptions

Subscription documents are exposed as raw strings for use with a `graphql-ws`
client:

```typescript
import { createGraphqlClient } from '@/lib/graphql/client'
import { createClient as createWsClient } from 'graphql-ws'

const client = createGraphqlClient({
  endpoint: 'http://localhost:5173/api/graphql',
  apiKey: 'pk_...',
})

const wsClient = createWsClient({
  url: 'ws://localhost:5173/api/graphql',
  connectionParams: { 'X-API-Key': 'pk_...' },
})

wsClient.subscribe(
  { query: client.subscriptions.sessionUpdated },
  {
    next: (data) => console.log('Session updated:', data),
    error: (err) => console.error('Subscription error:', err),
    complete: () => console.log('Subscription closed'),
  },
)
```

## Type Safety

All types are generated by `@graphql-codegen` from:

- **Schema**: `src/lib/graphql/schema.graphql`
- **Operations**: `src/lib/graphql/operations/*.graphql`

Generated types: `src/lib/graphql/generated/types.ts`

Re-exported types include: `Session`, `EmotionAnalysis`, `EmotionVector`,
`EmotionDimensions`, `ConversationTurn`, `InterventionRecord`,
`AnonymizedMetrics`, `PrivacyMetrics`, and all enum types.

## Authentication

Dual-mode auth (same as REST API):

- **API Key**: Set `apiKey` in config → sends `X-API-Key` header
- **JWT**: Set `jwt` in config → sends `Authorization: Bearer` header

Field-level security is enforced server-side via `@auth` and
`@auth(scope: "admin")` directives.

## Regenerating Types

```bash
pnpm codegen:graphql
```

This runs `graphql-codegen` with config from `codegen.ts`, regenerating
`src/lib/graphql/generated/types.ts` from the schema and operation documents.

## Browser Usage

The client uses `graphql-request` which auto-detects `fetch` in browser
environments. No additional polyfills needed in modern browsers. For Node 18+,
`fetch` is built-in.
