# Struct Build Agent - Branch Naming Convention

## Configuration

**Branch Prefix**: `struct/`

Set this in **Settings → Coding Agent → Struct → Branch Naming** in the Struct
web app.

## Pattern

```
struct/<type>-<short-description>
```

### Types

| Type       | Use Case                 | Examples                              |
| ---------- | ------------------------ | ------------------------------------- |
| `fix`      | Bug fixes                | `struct/fix-checkout-timeout`         |
| `feat`     | New features             | `struct/feat-add-bias-metric`         |
| `refactor` | Code restructuring       | `struct/refactor-auth-service`        |
| `docs`     | Documentation            | `struct/docs-update-api-guide`        |
| `test`     | Test additions/fixes     | `struct/test-bias-detection-coverage` |
| `chore`    | Maintenance              | `struct/chore-update-dependencies`    |
| `security` | Security fixes           | `struct/security-fix-token-leak`      |
| `perf`     | Performance improvements | `struct/perf-optimize-db-queries`     |

### Description Guidelines

- **Short**: 3-6 words max
- **Kebab-case**: lowercase with hyphens
- **Descriptive**: Clear what the change addresses
- **No issue numbers**: Struct links PR to investigation automatically

### Good Examples

```
struct/fix-redis-connection-leak
struct/feat-add-therapy-session-analytics
struct/fix-bias-detection-false-positive
struct/refactor-mcp-authentication-flow
struct/security-fix-jwt-token-validation
struct/perf-optimize-vector-search
struct/docs-update-struct-integration-guide
struct/test-add-integration-coverage
struct/chore-update-node-24-dependencies
```

### Bad Examples

```
struct/fix-bug                          # Too vague
struct/fix-issue-123                    # Includes issue number
struct/feat-add-new-feature-for-users   # Too long
struct/FIX-REDIS-LEAK                   # Wrong case
struct/fix redis connection leak        # Spaces instead of hyphens
struct/hotfix-urgent                    # Non-standard type
```

## Validation

The CI workflow (`.github/workflows/struct-setup.yml`) validates branch naming
follows this convention.

## GitHub Branch Protection

For `struct/*` branches, configure branch protection to allow:

- Force pushes (needed for Build Agent iterations)
- Admin bypass for Struct bot
- Required status checks from CI
