What it does

// three things, nothing else

Scan

Detect slop patterns and measure density. See exactly how much of your dataset is filler.

$ deslop scan data.jsonl

Clean

Regex-powered replacement. Deterministic, fast, free. No API calls, no data leaves your machine.

$ deslop clean data.jsonl -o clean.jsonl

Regen

LLM-powered rewriting via Ollama. Context-aware, local, optional. Your data stays on your machine.

$ deslop regen data.jsonl --model llama3.2

Three modes

// pick your depth

read-only

scan

Read-only analysis. Count patterns, calculate density. No modifications.

regex

clean

Regex replacement. Deterministic, fast, free. Output to file or stdout.

llm

ollama

LLM rewriting. Context-aware, local, optional. Requires Ollama.

// install in one line

$ pip install deslop-cli
$ deslop scan your-data.jsonl
