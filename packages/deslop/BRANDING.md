## Color Palette

| Name       | Hex       | Usage                                       |
| ---------- | --------- | ------------------------------------------- |
| Background | `#0D0D0D` | Page/app background                         |
| Surface    | `#1A1A1A` | Cards, panels                               |
| Border     | `#2A2A2A` | Dividers, rules                             |
| Primary    | `#FFFFFF` | Headings, emphasis                          |
| Secondary  | `#A0A0A0` | Body text, muted                            |
| Accent     | `#00FF41` | Terminal green — links, success, highlights |
| Error      | `#FF3333` | Slop detected, failures                     |
| Warning    | `#FFD700` | Medium severity, caution                    |

## Typography

**Font stack**:
`ui-monospace, SFMono-Regular, "SF Mono", Menlo, Consolas, "Liberation Mono", monospace`

No Google Fonts. No web fonts. System monospace only. The tool runs in terminals
— its brand should look like it lives there too.

## Voice & Tone

- Direct. No fluff. No "please", no "thank you for using".
- Dry humor welcome. "happy to help" → deleted.
- Technical precision over marketing language.
- First person plural ("we") is forbidden. Third person or imperative.

## Tagline

`clean your data.`

Lowercase. Period. No exclamation marks ever.

## Usage Rules

1. **ASCII art is the logo.** Never replace it with a raster/vector image.
2. **Terminal green is sacred.** `#00FF41` is the only color that appears in
   both dark and light contexts.
3. **Monospace everything.** If it has letters, it's monospace.
4. **No decorative elements.** Borders, shadows, gradients — all forbidden.
   Density IS the aesthetic.
5. **Consistency across surfaces.** README, landing page, CLI output, docs —
   same palette, same voice, same density.
