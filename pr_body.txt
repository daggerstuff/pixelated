💡 What:
Extracted the `tabIcons` static mapping object from the `EnhancedBiasDetectionInterface` functional component to the module scope (as `TAB_ICONS`).

🎯 Why:
To achieve O(1) lookup and prevent the object and its inner React elements (`<ChartBar />`, `<Search />`, etc.) from being unnecessarily recreated on every single render cycle, preventing memory allocations and small performance impacts.

📊 Impact:
Prevents unnecessary re-renders and allocations of static UI configurations in the Bias Detection Interface.

🔬 Measurement:
Reviewers can verify the speedup by checking the React DevTools Profiler while toggling through tabs or using the dashboard, noticing reduced render time.
